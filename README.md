# 루틴 퀘스트 · 도트 RPG 에디션

업로드한 HTML을 Android Chrome에서 설치 가능한 PWA로 구성했습니다.

## 설치
1. GitHub Pages를 `main` 브랜치의 root 폴더로 배포합니다.
2. 생성된 HTTPS 주소를 Android Chrome에서 엽니다.
3. Chrome 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
4. 첫 실행에서 오프라인 캐시가 준비되면 오프라인에서도 사용할 수 있습니다.

## 기록
퀘스트 데이터는 기기 내 브라우저 저장소에 저장됩니다. 설정에서 JSON 백업/복원을 이용하세요. 자동 동기화는 제공하지 않습니다.

참고: 현재 결과물은 설치형 웹앱(PWA)입니다. 서명된 네이티브 APK는 별도 Android 빌드가 필요합니다.
